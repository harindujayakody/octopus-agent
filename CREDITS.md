## Thanks and inspiration

Octopus Agent is inspired by and built on
**[ShardBrowser](https://github.com/ProxyShard/ShardBrowser)**, the
open-source anti-detect browser launcher by the ShardBrowser team, used
under the MIT License. Its launcher, profile and fingerprint tools,
automation API, MCP server, SDKs and team server are the foundation this
project grew from. Thank you for sharing it.

The patched Chromium engine that applies fingerprints is built and
published by ShardBrowser; Octopus Agent downloads it from them under
their own terms (see [README → Licensing](README.md#licensing)).

## Open-source projects

* [Tauri](https://tauri.app): desktop shell, updater and notifications
* [React](https://react.dev) and [Vite](https://vite.dev): the interface
* [Chromium](https://www.chromium.org),
  [Chrome for Testing](https://googlechromelabs.github.io/chrome-for-testing/) and
  [Mozilla Firefox](https://www.mozilla.org/firefox/): the stock browsers
